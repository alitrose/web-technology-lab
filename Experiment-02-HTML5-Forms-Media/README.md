## Aim
To design and develop an interactive HTML5 Showcase Webpage incorporating advanced HTML5 semantic elements, comprehensive form controls with input types and validation, audio, video multimedia elements, canvas/iframe embedding, and tables.

---

## Description
HTML5 introduces a powerful collection of form input controls, structural semantic tags, and native multimedia playback capabilities without requiring third-party plugins. This exercise demonstrates the implementation of modern HTML5 form elements including text, email, password, tel, date of birth, radio buttons, checkboxes, range sliders, file upload (resume), select dropdowns, and progress bars. Additionally, native <audio> and <video> elements with playback controls, downloadable file links, and embedded <iframe> elements are integrated into a visually styled interface using internal CSS.

---

## Procedure
1. Created a new HTML5 document named index.html with <!DOCTYPE html> and UTF-8 charset meta tag.
2. Applied modern CSS styling including a linear-gradient header, responsive container sections with card styling, rounded borders, and subtle box shadows.
3. Created a Description section (<section>) explaining the major features of the webpage.
4. Added an Image section (<section>) displaying an external high-resolution sample image.
5. Implemented a Hyperlink section (<section>) with target="_blank" links opening popular websites in new tabs.
6. Designed an HTML5 Elements summary table using <table>, <tr>, <th>, and <td> with border styling.
7. Constructed a comprehensive Student Registration Form within a <fieldset> with <legend> containing various input types: text, email, password, tel, date, radio buttons for gender, checkboxes for skills, range slider for knowledge level, file input for resume, select dropdown for courses, and a <progress> meter.
8. Embedded native multimedia elements: an <audio controls> player sourcing an MP3 file and a <video controls> player sourcing an MP4 file.
9. Added a Download section providing a direct download link using the HTML5 download attribute.
10. Integrated an <iframe> element to embed external web content (video player).
11. Verified the webpage rendering, form controls, and multimedia playback across modern web browsers.
