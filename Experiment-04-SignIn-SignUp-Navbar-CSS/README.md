## Aim
To develop an advanced CSS3 webpage demonstrating advanced styling techniques including navigation bars, rounded corners (border-radius), box shadows, border images, multiple background images, form styling with interactive pseudo-classes, and zebra-striped tables.

---

## Description
CSS3 introduces advanced visual styling features that reduce dependency on image editors and external graphic assets. Key properties include border-radius for rounded geometries, box-shadow for realistic depth and elevation, border-image for custom graphical borders, and multiple layered background images using comma-separated background-image URLs. Furthermore, CSS pseudo-classes like :focus, :required, :valid, :invalid, and :hover provide interactive real-time visual feedback for form inputs and table rows, while :nth-child(odd) and :nth-child(even) enable alternating zebra striped tables.

---

## Procedure
1. Created an HTML document index.html linked to an external stylesheet style.css.
2. Constructed a header with a linear-gradient background and a top navigation menu bar with hover color transitions.
3. Designed a box demonstrating border-radius: 25px and box-shadow: 5px 5px 10px gray.
4. Implemented a border-box container showcasing border-image: url('image/border.png') 30 round.
5. Configured a multi-background container (.multi-bg) with two layered background images (flower.png and background.png) using distinct repeat, position, and sizing rules.
6. Built a registration form styled with interactive CSS pseudo-classes: :focus (red border and light green background), :required (blue border), :valid (blue font), :invalid (red font), and submit button hover effect.
7. Created a data table styled with alternating zebra row colors using tr:nth-child(odd) and tr:nth-child(even), along with a tr:hover yellow highlight.
8. Verified the visual rendering and interactive form behavior in the web browser.
