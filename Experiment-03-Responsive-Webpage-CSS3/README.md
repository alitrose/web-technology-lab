## Aim
To design and implement a responsive webpage using HTML5 semantic elements and CSS3 Flexbox layout and Media Queries to ensure adaptive display across various screen resolutions.

---

## Description
Responsive Web Design (RWD) ensures that web applications render dynamically and gracefully across a wide range of devices and viewport sizes, including mobile smartphones, tablets, laptops, and wide desktop monitors. This is achieved using fluid grid concepts, CSS3 Flexible Box Layout (Flexbox), and CSS3 Media Queries (@media screen). HTML5 semantic elements like <header>, <nav>, <div class="container">, and <footer> provide clear document semantics. The flex layout splits content into a flexible main content area and a sidebar, while media queries reorient the flexible layout into a stacked column layout on smaller screens.

---

## Procedure
1. Designed the webpage layout structure with HTML5 semantic elements: <header>, <nav>, container <div>, main content area, sidebar, and <footer>.
2. Created a flexible navigation bar using display: flex with justify-content: center, wrap capabilities, and hover transition effects.
3. Configured the main container with display: flex and flex-wrap: wrap.
4. Assigned flex: 3 to the main content container and flex: 1 to the sidebar container, creating a balanced multi-column layout.
5. Included student information (Name: ALIT ROSE M M, Register No: URK24CS9042) in the sidebar along with quick navigation links.
6. Implemented CSS3 media queries with @media screen and (max-width: 768px) to dynamically switch container flex-direction and navigation flex-direction to column for mobile viewports.
7. Formatted typography, padding, margins, borders, and color contrasts for readability and visual appeal.
8. Tested responsive behavior on both desktop and mobile viewports in browser developer tools.
